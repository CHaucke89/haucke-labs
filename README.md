# Haucke Labs

Source for [hauckelabs.dev](https://hauckelabs.dev), a showcase of my open source projects.

Built with SvelteKit and TypeScript, prerendered and deployed to Cloudflare Workers.

## Development

```sh
pnpm install
pnpm dev        # local dev server
pnpm check      # type-check
pnpm build      # production build
pnpm deploy     # build and deploy with wrangler
```

Project content lives in `src/lib/projects.ts`.
